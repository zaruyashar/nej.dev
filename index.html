Today I apply that same meticulous precision much earlier in the process: instead of finding defects after release, I focus on preventing them at design time. I write clean, maintainable, secure-by-design code. I do not merely write syntax; I engineer robust systems that prioritize scalability and reliability.

I recently completed a 320-hour, full-time backend engineering program run with the Istanbul Chamber of Commerce, building 11 progressively complex ASP.NET Core applications. My Goal: To bring my multidimensional perspective on quality, security, and architecture to a forward-thinking engineering team building backend and AI systems.

03.Projects

Capstone Project

EKOMART — E-Commerce Platform

A full N-Tier e-commerce platform (Entities → Data → Business → Api/Web) with a dual EF Core/Dapper data layer behind a shared Repository/Unit of Work abstraction. Features ASP.NET Identity, Google OAuth, and JWT across separate MVC and API surfaces, atomic transaction-safe checkout with real-time stock re-validation, PDF/Excel/QR generation, and an AI-powered review moderation pipeline (translation and toxicity classification via the Hugging Face Inference API). Deployed to production on Azure App Service with a Cloudflare-proxied custom domain and GitHub Actions CI/CD.

ASP.NET Core MVC EF Core + Dapper Identity / OAuth / JWT Azure

Türk Tarım — Enterprise CMS

An enterprise-grade Content Management System developed in an N-Tier architecture using C# and .NET, featuring Role-Based Access Control (RBAC) and secure file management. Defensive programming practices are applied project-wide, with mitigations for common vulnerabilities such as CSRF, XSS, and mass assignment.

ASP.NET Core MVC EF Core MSSQL N-Tier

The Venue — Event Management System

A decoupled API/MVC venue-booking system built with Dapper and T-SQL stored procedures for high-performance data access. Applies the Repository pattern and DTOs end-to-end, with sliding-window rate limiting to protect the API from abuse.

ASP.NET Core Web API Dapper T-SQL Rate Limiting
